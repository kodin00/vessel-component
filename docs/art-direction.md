# Vessel art direction

Interactive biomechanical interface specimen lab, inspired by the supplied H. R. Giger reference. Sculptural surfaces are generated raster assets, with native HTML for text and controls. CSS handles layout, typography, compositing, and interaction feedback.

Palette: void #080908, gunmetal #171916, tarnished silver #787b70, bone #d2cebf, muted olive #9caa8c. Typography: Cormorant Garamond display, system monospace utility. Layout: large specimen viewer between command bank and signal panel, then interactive components. Signature: generated alien skull and ribbed metal frame.

## Generated assets

Built-in image generation; original PNGs in dist/assets. No CSS illustrations.
